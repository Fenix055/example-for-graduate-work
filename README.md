# Дипломный проект: Бэкенд-платформа веб-сервиса объявлений
Данный проект представляет собой полноценную серверную часть для платформы размещения и управления объявлениями о продаже товаров.
Бэкенд интегрирован с Frontend, упакованной в Docker-контейнер.

## Технологический стек

* **Язык разработки:** Java 17
* **Фреймворк:** Spring Boot 2.7+
* **Система сборки:** Maven
* **База данных:** PostgreSQL
* **Управление миграциями:** Liquibase
* **Документация API:** OpenAPI 3.0 / Swagger UI (Springdoc-openapi)
* **Утилиты:** Lombok

## Архитектура приложения

1. **Слой представления (REST Controllers):** Ловит HTTP-запросы, валидирует входящие Multipart и JSON данные, возвращает строго регламентированные контрактом OpenAPI DTO-объекты.
2. **Сетевой слой (DTO):** Изолирован от сущностей базы данных. Классы снабжены аннотациями `@Schema` для автоматической генерации интерактивной документации в Swagger UI.
3. **Бизнес-логика (Services):** Обрабатывает логику приложения, управляет транзакциями, выполняет безопасный маппинг (DTO $\leftrightarrow$ Model) с защитой от `NullPointerException`.
4. **Безопасность (Spring Security):** Реализована кастомная авторизация через базу данных. Входящие email-адреса (логины) приводятся к нижнему регистру (`lowercase`), защищая UX от визуальных особенностей фронтенд-шрифтов. Пароли хэшируются по стандарту `BCrypt`.
5. **Доступ к данным (Repositories):** Spring Data JPA репозитории для прямого взаимодействия с PostgreSQL.

## Работа с медиафайлами

Загружаемые файлы (изображения товаров, аватарки) сохраняются в файловую систему сервера в изолированные директории:
* `market-images/ads/` — изображения товаров.
* `market-images/users/` — аватарки пользователей.

## Инструкции по запуску проекта

### 1. Настройка и запуск базы данных PostgreSQL
1. Установите и запустите СУБД PostgreSQL.
2. Создайте пустую базу данных с именем `Market`.
3. Откройте файл `src/main/resources/application.properties` и укажите параметры подключения:
   ```properties
   spring.datasource.url=jdbc:postgresql://localhost:5432/Market
   spring.datasource.username=ваш_логин
   spring.datasource.password=ваш_пароль
   ```

### 2. Запуск Бэкенда (Backend)
1. Откройте проект в IntelliJ IDEA.
2. Дождитесь загрузки Maven-зависимостей.
3. Запустите проект через главный класс `HomeworkApplication.java`. При старте **Liquibase** автоматически развернет структуру таблиц в вашей базе данных `Market`.
4. Интерактивная документация Swagger UI будет доступна по адресу: `http://localhost:8080/swagger-ui/index.html`

### 3. Запуск Фронтенда (Frontend) в Docker
1. Убедитесь, что у вас запущен Docker Desktop.
2. В командной строке пропишите `docker run -p 3000:3000 --rm ghcr.io/dmitry-bizin/front-react-avito:v1.21`
3. Графический интерфейс сайта будет доступен в браузере по адресу: `http://localhost:3000`
